# Arcle V7 — The Unfolding Company

## Source of truth

`public/v7-concept.png` をV7の視覚基準とする。

- 白い面が床から立ち上がり、空間になる
- 細い隙間へカメラが近づき、そのまま内部を通過する
- 紙、半透明ガラス、アルミ、布、色付き樹脂
- 生成り、墨色、銀を基調に、朱・青・黄を奥で使う
- 現代建築、編集デザイン、キネティックアートの中間

## Scroll choreography

1. UNFOLD — 平面が立ち上がり、入口が生まれる
2. LOCK — アルミフレームが噛み合い、仕事を支える構造になる
3. ALIGN — 透明レイヤーと点が重なり、データの意味が現れる
4. RECOMPOSE — 知識のブロックが何度も組み替わる
5. OPEN — 巨大な色面が左右へ開き、価値が外へ放たれる

## Non-goals

- 自然景観、植物、水、岩、山
- キャラクター、ロボット、マスコット
- モニター、ダッシュボード、オフィスの再現
- ネオン、宇宙、ホログラム、サイバー回路
- 一枚画像のズームやブラーで移動を偽装すること

## Implementation

- React Three Fiber + Three.jsのリアルタイム3D
- CatmullRomCurve3に沿ってカメラを連続移動
- オブジェクトの折り、整列、再構成、開閉もスクロール値で制御
- 逆スクロールで全工程を逆再生
- モバイル用FOV・コピー配置・負荷調整
- prefers-reduced-motionでは承認済みコンセプト画像へ切り替える
