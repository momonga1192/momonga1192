# Arcle（アークル）

> 愛知県一宮市の個人事業。専任のIT担当者がいない東海（愛知・岐阜・三重）の中小企業の「IT部門」として、情シス代行、データ活用支援（Power BI・Tableau）、生成AI活用支援、月額制のホームページ制作をまとめて引き受けています。代表の栗原勇太が、相談から設定・運用まで直接担当します。

Arcle is a sole proprietorship based in Ichinomiya, Aichi, Japan, run by Yuta Kurihara. It acts as an outsourced IT department for small and medium-sized businesses in the Tokai region (Aichi, Gifu, Mie): IT support outsourcing, data visualization with Power BI / Tableau, generative AI adoption, and subscription-based website production.

- [情シス代行](https://www.arcle.net/josys): IT担当者がいない会社の代わりに、PC・アカウント管理、トラブル対応、セキュリティ、ツール導入を引き受けます。ライト月額3万円〜（相談窓口・リモート対応）、スタンダード月額15万円〜（PC初期設定・アカウント管理・訪問を含む）、プレミアム月額30万円〜（IT戦略・運用保守まで）。愛知・岐阜・三重は訪問します
- [データ活用支援](https://www.arcle.net/data-consulting): Power BI・Tableauでの経営ダッシュボード構築、データ基盤、KPI設計、研修。初期費用0円、ライト月額5万円〜、スタンダード月額15万円〜、プレミアム月額30万円〜
- [生成AI活用支援](https://www.arcle.net/gen-ai): ChatGPTなどの導入と社内ルールづくり、社内文書を検索するAIチャットボット（RAG）の開発、研修、業務自動化。導入支援5万円〜、活用定着20万円〜、独自開発50万円〜
- [月額制ホームページ制作](https://www.arcle.net/web-production): 初期費用0円、月額4,800円〜（ライト4,800円・スタンダード7,500円・オーダーメイド9,800円）。サーバー・ドメイン・メール・スマホ対応・更新を含みます
- [IT健康診断](https://www.arcle.net/it-check): 3分で会社のIT環境の弱いところが分かる無料の診断
