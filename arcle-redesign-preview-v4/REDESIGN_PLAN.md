# Arcle Storybook V4 — 制作計画

## 1. コンセプト

V4は「会社のITサービスを説明するページ」ではなく、小さな案内役と仕事の迷子を迎えにいく横長の立体絵本にする。

画面を下へスクロールすると、3Dカメラは横方向へ進む。キャラクター「アル」が青い糸を持って歩き、5つの舞台を一本につないでいく。

V3の自然な3D空間を前後へ移動する方式とは、カメラ、物語、コピー、キャラクター、UIをすべて分ける。

## 2. キャラクター「アル」

- クリーム色の丸い身体、濃い緑の靴、青い襟と頭の円弧。
- 顔は目と小さな口だけ。子ども向けに寄りすぎない素朴なクレイ造形。
- スクロール速度に応じて足、腕、身体が動く。
- 上スクロールでは向きを変え、同じ道を戻る。
- 青い糸玉を持ち、会社の中で散らばった課題をつなぐ役割。
- 各章で一言だけ話し、サービスの意味を生活の言葉に翻訳する。

## 3. 5つの章

1. **はじまり** — 散らばったカードや石の前で、仕事の迷子を拾い始める。
2. **情シス** — 緑の屋根が端末やアカウントを雨から守る。
3. **データ** — ばらばらの柱がスクロールに合わせて順番に伸びる。
4. **生成AI** — 開いた本から知識の核と紙カードが浮かぶ。
5. **Web** — 完成した紙面から紙飛行機が外の世界へ飛び出す。

## 4. 技術構成

- Three.js / React Three Fiberによるライブ3D。
- スクロール進捗0〜1を横方向72単位へ変換。
- カメラとキャラクターを同じ進捗値で追従させる。
- 現在位置を減衰補間し、ホイールの段差を吸収。
- データ柱、紙飛行機などは章内のローカル進捗で動かす。
- 3Dは装飾扱いとし、見出し、本文、ナビは操作可能なHTMLで実装。

## 5. デザイン

- 暖かな紙色、クレイ、木、陶器、くすんだ青・緑・橙・紫。
- 大きく太いコピーと、小さな物語番号の組み合わせ。
- 下層のサービス一覧は2列のカードへ再設計。
- サイバー感、黒背景、電子回路、ロボット表現は使わない。

## 6. レスポンシブとアクセシビリティ

- スマートフォンはカメラFOVを広げ、コピーを画面下部へ配置。
- スマートフォンの章ナビは右下の縦表示へ変更。
- `prefers-reduced-motion`では常時描画を止め、静かな背景へ切り替える。
- キーボードで操作できる通常ボタンとリンクを使用。
