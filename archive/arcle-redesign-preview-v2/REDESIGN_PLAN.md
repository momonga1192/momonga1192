# Arcle Scroll World V2 — 制作計画

## 1. 前回の失敗

- 1枚の画像を5本の動画に変換しただけで、シーンの意味と視覚差がなかった。
- `currentTime`をスクロールに同期する仕組みは入ったが、素材設計が欠落していた。
- 参考サイトの本質である「場所から場所へ移動する感覚」を再現できていなかった。

このV2では、前回の画像・動画を流用しない。

## 2. 参考サイトから踏襲する仕組み

- 画面を固定し、その背後に長いスクロールトラックを置く。
- シーンごとに独立した静止画と短い動画を持つ。
- スクロール位置を各動画の `currentTime` に割り当て、上下どちらにもスクラブする。
- シーン動画と場面間トランジションを交互に並べる。
- 境界では前後の映像を短くクロスフェードし、空白フレームを出さない。
- コピー、上部ナビ、右側ルート、進捗バーを同じスクロール値で同期する。
- `prefers-reduced-motion` では静止画のクロスフェードへ切り替える。

## 3. Arcle版の5シーン

全シーン共通：16:9、柔らかいアイボリー、コバルトブルーの円弧、少量のアンバー、上質なクレイ3D、同じ光源・レンズ・素材感。文字・人物・ロゴは画像に入れない。

1. **Connect / はじまり**
   - 中央のArcleハブから4つの業務エリアへ円弧が伸びる全景。
   - 「散らばったITがひとつにつながる」を視覚化。
2. **IT Management / 情シス**
   - PC、アカウント、盾、クラウドが整然とつながるサポートステーション。
   - トラブルから安定運用へ移る安心感。
3. **Data & Insight / データ**
   - 複数の表・データブロックが一本の流れに集まり、明快なダッシュボードへ変わる分析室。
   - 数字が判断材料になる瞬間。
4. **Generative AI / 生成AI**
   - 文書・社内知識・問い合わせが安全なAIコアへ入り、タスクカードとして出てくる自動化ラボ。
   - ロボットではなく、仕事の仕組みとしてのAI。
5. **Web & Growth / Web**
   - 会社の価値がWebページ、検索、問い合わせへ届き、次の縁が生まれる発信ポータル。
   - 最終CTAへ自然につながる明るい出口。

## 4. 動画設計

- 5本のシーン動画：各3秒、1280×720、30fps、無音。
- 4本の場面間トランジション：各2秒、前シーンの終端と次シーンの始端を接続。
- H.264 / `yuv420p` / `faststart` / 短いGOPで、スクラブ時の待ちを減らす。
- シーン動画は単純ズームだけにしない。背景のカメラ移動に加え、HTMLレイヤーのノード、カード、リング、データバーを別速度で動かす。
- トランジションでは円形マスク、発光する接続線、色の引き継ぎで場面転換を見せる。

## 5. スクロール設計

- シーン滞在：1.35 viewport height。
- トランジション：0.75 viewport height。
- 9区間を交互に並べ、区間ごとに動画時間へ正規化する。
- コピーは各シーン中央付近で最大表示し、トランジションではフェードアウトする。
- スクロールを止めた時に映像が遅れて追いつくよう、目標時間へ緩やかに補間する。

## 6. 合格条件

- [ ] 5シーンが一目で別内容と分かり、同じ画像の使い回しがない。
- [ ] 下スクロールで進み、上スクロールで同じ軌道を自然に戻る。
- [ ] シーン境界に白・黒・未読み込みフレームが出ない。
- [ ] コピーとナビの表示シーンが映像と一致する。
- [ ] PCでスクラブ中の引っ掛かりが目立たない。
- [ ] スマホで文字が主役を隠さず、動画が重い場合は静止画へ安全にフォールバックする。
- [ ] 動きを減らす設定では動画スクラブを止める。
- [ ] 本番ビルドが成功する。
- [ ] 既存サイトとV1プレビューを変更しない。
