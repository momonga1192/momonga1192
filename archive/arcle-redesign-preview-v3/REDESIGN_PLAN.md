# Arcle Natural Journey V3 — 制作計画

## 1. V3で解決すること

V2はシーン画像を動画化してスクロールに同期したが、動きの中心はパンとズームだった。そのため「空間の中へ入る」感覚が弱かった。

V3では静止画とMP4を主役にせず、ブラウザ内に本物の3D空間を構築する。スクロール値を3Dカメラの座標と向きへ割り当て、手前のアーチ・植物・家具を通過する視差で移動を見せる。

## 2. デザイン方針

- サイバー感を抑え、木、紙、石、陶器、植物を中心にする。
- 背景は暖かなアイボリー。柔らかい昼光と薄い霧で奥行きを出す。
- Arcleの青は発光色ではなく、床の案内線や小さなUIに限定する。
- ネオン、黒背景、電子回路、グリッド、過剰なガラス表現は使わない。
- 形状は角を丸め、庭やアトリエを巡るような安心感をつくる。

## 3. 5つの立体空間

1. **Connection Garden** — 複数の円弧が穏やかにつながる入口。
2. **IT Studio** — 木の机、整ったカード、植物のある情シスの仕事場。
3. **Data Terrace** — 木と陶器の柱がグラフのように立ち上がる分析空間。
4. **AI Library** — 紙のカードと知識の核が循環する静かな書庫。
5. **Web Atelier** — 紙面を組み立てるような明るい制作アトリエ。

各空間の入口には大きな木製アーチを置き、カメラがその穴を実際に通過する。

## 4. カメラとスクロール

- Three.jsのCatmull-Rom曲線上に14個のカメラ制御点を配置。
- スクロール進捗を曲線の0〜1へ割り当てる。
- カメラは少し先の曲線位置を常に見るため、前進しながら自然に旋回する。
- 現在値を目標値へ減衰補間し、ホイール操作の段差を吸収する。
- 上方向にスクロールすると、同じ3D経路を逆向きに戻る。
- 5つのコピー、ナビ、右側ルート、進捗バーを同じ値で同期する。

## 5. 常時アニメーション

- 紙カードと円弧の小さな浮遊。
- 空間を漂う控えめな光の粒。
- 植物、石、前景オブジェクトによる視差。
- カメラが止まっても空間が完全な静止画に見えない程度の微細な動き。

## 6. 性能とアクセシビリティ

- DPRを最大1.55に制限し、形状は軽量なプリミティブで構成。
- テクスチャ画像や外部3Dモデルを読み込まず、初期通信量を抑える。
- スマートフォンではFOVを広げ、コピーを下部へ移して3Dとの干渉を避ける。
- `prefers-reduced-motion`ではCanvasを静止画へ置き換える。
- 3Dは装飾扱いとし、本文とナビは通常のHTMLで操作可能にする。

## 7. 合格条件

- [x] カメラが3D空間内を前後左右に移動する。
- [x] 手前のアーチや柱を通過し、明確な視差がある。
- [x] 5空間の目的と形状が一目で区別できる。
- [x] サイバー感を抑え、自然素材と昼光を中心にしている。
- [x] 下スクロールと逆スクロールの両方に追従する。
- [x] デスクトップと390×844のスマートフォンでコピーが読める。
- [x] 本番ビルドが成功する。
- [x] 既存サイト、V1、V2を変更しない。
