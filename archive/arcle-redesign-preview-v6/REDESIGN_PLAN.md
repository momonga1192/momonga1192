# Arcle V6 — The Living Current

## 修正した解釈

- 自由にする対象はデザインの世界観。
- 残す核は、スクロールに同期してカメラが世界の奥へ入っていく体験。
- キャラクター、ロボット、モニター、サイバー表現は使わない。
- 一枚絵の拡大ではなく、Three.jsの実空間をカメラが連続移動する。

## 世界の構成

ひと続きの水脈が、Arcleの4領域を異なる自然現象として通過する。

1. 合流点 — 散らばる課題がひとつの流れになる
2. 石の門 — 情シスが静かな土台になる。カメラは橋を実際にくぐる
3. 地層と棚田 — データが積層し、意味ある形になる
4. 知識の森 — 会社の知識が根づき、生成AIとして育つ
5. 光の地平線 — Webが価値を外の世界へひらく

## アートディレクション

- 素材: 水、石、土、木、紙、葉
- 色: 苔の緑、浅い水色、土の茶、朝日の琥珀
- 光: 暖かな斜光と薄い霧
- 形: 人工物をそのまま描かず、仕事の意味を自然の現象へ翻訳
- 動き: スクロール移動、川の曲線、橋の通過、棚田の柱、知識の核、風に乗る紙片

## 実装方針

- React Three Fiber + Three.jsによるリアルタイム3D
- CatmullRomCurve3に沿うカメラパス
- 960vhのスクロールを5章にマッピング
- 逆スクロールでも同じ経路を戻れる
- モバイルはFOVとコピー位置を最適化
- prefers-reduced-motionでは静的な景観へフォールバック
