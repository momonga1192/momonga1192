# Arcle Pocket V5 — コンセプト

## 1. 前作から切り離したもの

V3/V4に共通していたライブ3D、カメラ移動、5場面のスクロール物語、自然素材のクレイ空間をすべて使わない。

V5は、ユーザーが自分の困りごとを選ぶことでページの内容が変わる「相談ツール」にする。スクロールは通常の閲覧にだけ使い、主役の操作はクリックとドラッグにする。

## 2. 中心体験

- 4枚の困りごとカードをクリック、またはキャラクターへドラッグする。
- キャラクター「ポッケ」がカードを食べ、身体とポケットが反応する。
- 選択した内容に応じて、右側に相談の順番と具体的な最初の行動が組み上がる。
- 複数の課題を同時に選べる。サービスを先に決める必要はない。
- 選択した内容を件名に含めて、そのまま相談メールを開始できる。

## 3. キャラクター「ポッケ」

- 2DのHTML/CSS造形。画像、3Dモデル、動画は使わない。
- 酸味のある黄緑の身体、白い目、青い大きなポケット。
- マウス位置に目線が追従。
- カード投入時に身体、耳、口が短く動く。
- ポケット内に、選択したカード色の丸が増える。
- 楽しいが、幼児向けには見えない太い線とエディトリアルな構成。

## 4. ビジュアル

- 紙色の背景、黒い太線、強い青、ミント、コーラル、紫、黄色。
- スイス系エディトリアルデザインと手描きキャラクターの中間。
- 影は柔らかい立体感ではなく、黒いオフセットシャドウ。
- コピーは太く大きく、情報ラベルは小さな等幅書体。
- 下層は非対称カード、ステッカー、横に流れる単語で構成。

## 5. 合格条件

- [x] V3/V4と異なり、3Dとスクロール場面転換を使わない。
- [x] カードがクリックとドラッグの両方で選択できる。
- [x] 選択内容に応じて相談ルートが変化する。
- [x] キャラクターの目線と投入リアクションが動く。
- [x] キーボード・タッチでも主要操作が可能。
- [x] スマートフォンで1列の操作画面になる。
- [x] 軽減モーション設定でアニメーションを停止する。
- [x] 既存サイト、V1〜V4を変更しない。

## 6. 成果物

- `app/InteractivePocket.tsx` — カード選択、ドラッグ、キャラクター、相談ルート生成。
- `app/page.tsx` — V5全体のコンテンツ。
- `app/globals.css` — V5の2Dエディトリアルデザインとレスポンシブ。
- `public/og-v5.png` — V5専用共有カード。
- ローカルプレビュー：`http://localhost:3004/`。
