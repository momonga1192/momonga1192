# ロリポップからVercelへのDNS設定変更ガイド

ロリポップサーバーで公開しているサイトをVercelに移行する際のDNS設定変更手順です。

## 🔍 確認すべきDNSレコード

お名前.comの管理画面で、現在設定されているDNSレコードを確認してください。

### 削除・変更が必要なレコード

#### 1. **Aレコード（ルートドメイン用）**
- **ホスト名**: `@`（または空白）
- **タイプ**: `A`
- **値**: ロリポップのIPアドレス（例: `153.126.xxx.xxx` など）
- **対応**: **削除または変更** → VercelのIPアドレス `76.76.21.21` に変更

#### 2. **CNAMEレコード（wwwサブドメイン用）**
- **ホスト名**: `www`
- **タイプ**: `CNAME`
- **値**: ロリポップのドメイン（例: `example.lolipop.jp` など）
- **対応**: **削除または変更** → `cname.vercel-dns.com` に変更

### 残すべきレコード（メール用など）

#### 3. **MXレコード（メール用）**
- **ホスト名**: `@`（または空白）
- **タイプ**: `MX`
- **値**: メールサーバーのアドレス
- **対応**: **そのまま残す**（メール機能を使っている場合）

#### 4. **TXTレコード（SPF/DKIMなど）**
- **ホスト名**: `@`（または空白）
- **タイプ**: `TXT`
- **値**: SPFレコードやDKIMレコードなど
- **対応**: **そのまま残す**（メール認証用）

#### 5. **その他のレコード**
- サブドメイン用のAレコードやCNAMEレコード（例: `mail.example.com`、`blog.example.com` など）
- **対応**: 用途に応じて判断（メールや別サービス用なら残す）

---

## 📝 お名前.comでの設定手順

### ステップ1: 現在のDNSレコードを確認

1. お名前.comの管理画面にログイン
2. 「ドメイン設定」をクリック
3. 対象のドメインを選択
4. 「DNS関連機能の設定」をクリック
5. 現在設定されているレコードを確認

### ステップ2: ロリポップ用のレコードを削除または変更

#### 方法A: レコードを削除して新規追加（推奨）

1. ロリポップ用のAレコード（ルートドメイン用）を削除
2. ロリポップ用のCNAMEレコード（www用）を削除
3. 新しいレコードを追加（下記参照）

#### 方法B: 既存レコードを編集

1. ロリポップ用のAレコードを選択
2. 「編集」をクリック
3. 値を `76.76.21.21` に変更
4. 保存

## 🔄 移行のタイミング

### 推奨手順

1. **Vercelでサイトをデプロイ**（まだドメインを設定しない）
2. **Vercelの一時URLで動作確認**（`https://your-project.vercel.app`）
3. **DNSレコードを変更**（ロリポップ用を削除/変更、Vercel用を追加）
4. **Vercelでカスタムドメインを設定**
5. **DNS設定の反映を待つ**（数時間〜48時間）
6. **動作確認**

### 注意点

- DNS設定の反映には時間がかかります（数時間〜最大48時間）
- 反映されるまでは、ロリポップのサイトが表示され続ける可能性があります
- メール機能を使っている場合は、MXレコードを削除しないでください

---

## 🛠️ トラブルシューティング

### 古いサイトが表示され続ける

- DNS設定の反映を待つ（最大48時間）
- ブラウザのキャッシュをクリア
- `nslookup your-domain.com` でDNS設定を確認

### メールが届かなくなった

- MXレコードが削除されていないか確認
- TXTレコード（SPF/DKIM）が残っているか確認

### 404エラーが表示される

- Vercelでカスタムドメインが正しく設定されているか確認
- `vercel.json` ファイルが正しく設定されているか確認

## 💡 補足情報

### ロリポップの一般的なDNS設定例

ロリポップでよく使われる設定：

```
Aレコード:
@ → 153.126.xxx.xxx（ロリポップのIPアドレス）

CNAMEレコード:
www → example.lolipop.jp（ロリポップのドメイン）
```

### Vercelへの移行後

```
Aレコード:
@ → 76.76.21.21（VercelのIPアドレス）

CNAMEレコード:
www → cname.vercel-dns.com（VercelのDNS）
```

### メール機能を使っている場合

メール機能を使っている場合は、以下のレコードを**必ず残してください**：

```
MXレコード:
@ → mail.example.com（メールサーバー）
優先度: 10

TXTレコード（SPF）:
@ → "v=spf1 include:lolipop.jp ~all"

TXTレコード（DKIM）:
（メールプロバイダーが提供するDKIMレコード）
```
