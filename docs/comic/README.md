# アメコミ版のイラスト設定資料

トップページのアメコミ版（`components/next/HomeComic.tsx`）で使うイラストの決まりごと。新しい絵を描くときは、この資料と `sheets/` の設定画を画像生成ツールに渡す。

## 設定画

| ファイル | 内容 |
|---|---|
| `sheets/hero-sheet.webp` | アークル・マン（正面・斜め・横・後ろ、表情4種）。胸のマークはこの絵の胸にあるものが正 |
| `sheets/cast-sheet.webp` | 脇役4人（全身と、困った顔・笑顔） |
| `sheets/villain-robot-sheet.webp` | ウイルスの怪物と、相棒ロボット |
| `prompt-style.txt` | これまでの絵で画像生成ツールに渡した、画風と主人公の指示文 |

## 画風

- 1950〜60年代のアメリカのスーパーヒーロー・コミック。強弱のある黒いインク線、ハッチング、ベタの黒い影
- ベンデイ・ドット（網点）の塗り、少しくすんだ印刷の色。ポップアート（リキテンスタイン風）
- 集中線・スピード線・ギザギザの爆発形は描いてよい
- 人物はリアル寄りのプロポーションで、表情はドラマチックに
- 配色：濃紺 `#1F2430`、ヒーローブルー `#3B6FE0`、からし色 `#F2B544`、珊瑚色 `#F07A5A`、紫 `#8E5BD0`、紙のクリーム色 `#FAF3E0`
- 事業の色を主役にするとき：情シス代行 `#3B6FE0`、データ活用 `#5B5BD6`、生成AI `#8E5BD0`、Web制作 `#C8509F`

## 登場人物

### アークル・マン（主人公）
- Arcleが変身したヒーロー。オリジナルで、実在のヒーローに似せない
- ツンツンした黒髪、目元に濃紺のマスク、細身で背が高い、さわやかな笑顔
- 青 `#3B6FE0` のスーツ。からし色 `#F2B544` のマント・ベルト・手袋・ブーツ
- 胸のマーク：からし色の円の中に、白い弧が上向きに2本重なった形。`sheets/hero-sheet.webp` の正面の胸にあるマークを正とする
  - アルファベット・「C」の形・S・ひし形・盾形にしない
  - 体が傾いているときは、マークも体の向きに合わせて傾ける（飛んでいる絵は45度くらい）
  - 絵ごとに形がずれたら、設定画の胸のマークに合わせて描き直すか、同じ形を胸の位置に重ねて直す（サービスの3枚はこの方法で直した）

## 絵に入れないもの

- 文字・数字・ロゴ・効果音の文字・吹き出し。効果音と吹き出しはページ側で重ねる（`components/next/comic.tsx`）
- 実在のヒーローのマークや衣装

## 描き方の手順

1. `codex exec` に、上の画風と登場人物の説明、設定画を `--image` で渡す
2. お悩みの絵は正方形 1024×1024、サービスの絵は横長 1536×1024。吹き出しを重ねる側に、網点だけの余白を残すよう指示する
3. 透過が必要な部品（演出用）は「背景は完全な透過」と指示し、保存後に透過を確かめる
4. できた絵は WebP に変換して `public/images/illust-comic/` に置く（幅：サービス 1100px、お悩み 640px、理由 720px）

## 部品に分けた絵（トップのお悩み・解決のコマ・サービス）

トップでは、絵を背景・人物・物・効果に分けて重ね、別々に動かしている。部品は `public/images/illust-comic/layers/` にあり、名前の頭で場面がわかる（`wp-` 情シス代行のお悩み、`wd-` データ活用、`wa-` 生成AI、`ww-` Web制作、`wo-` 解決のコマ、`sj-` `sd-` `sa-` `sw-` サービス4枚）。

- 作り方：完成形の絵を `codex exec` に渡し、「この場面から○○だけを、同じ大きさ・同じ位置で、背景透過で描く」と1部品ずつ頼む。背景の部品は、人物や物を取り除き、隠れていた部分を描き足してもらう
- ヒーローの部品には `sheets/hero-sheet.webp` も渡し、胸のマークを設定画どおりに描き直してもらう
- 重ねてずれた部品は、縮めたり位置をずらしたりして合わせる。顔にかかる紙なども、ここで動かす
- 変換：お悩み 幅720px、解決のコマ 1100px、サービス 900px。背景は網点で重くなるので、品質を少し下げる（WebP q62。ほかは q72）
- 動きは `index.css` の `.layer-*`（お悩み・解決のコマ）と `.tilt-*`（サービス）
